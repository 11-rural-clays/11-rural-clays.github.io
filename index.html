YouTube This tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service.

LIAG Uploader and Analytics is a private desktop tool used only by the owner of the Life Is Always Good and Everything for Mortals YouTube channels, on his own computer. It is not offered to anyone else.

Privacy Policy

YouTube API Services. The tool uses the YouTube Data API and the YouTube Analytics API. Google's handling of data is described in the Google Privacy Policy.

What it accesses. Only the owner's own channels: it uploads the owner's videos (as Private), with their thumbnails, captions and playlists; reads those channels' own statistics and comments; and, only after the owner approves each one, posts the owner's replies to comments. It does not access any other person's account or data.

How data is used and stored. Channel statistics go into a report on the owner's computer for his own planning. The sign-in token is kept in the macOS Keychain. Nothing is shared with, sold to or sent to any third party. No cookies or tracking are used.

Retention and deletion. Report data is kept on the owner's computer only as long as it is useful for planning, and can be deleted at any time by deleting the report files. Stored API data is refreshed or deleted at least every 30 days. To delete everything, remove the token from the Keychain and the report files from the computer. To request deletion or ask a question, email the contact below; requests are handled within 7 days.

Revoking access. Access can be revoked at any time from the Google security settings page: security.google.com/settings/security/permissions.
